Features

01 — 03
01

Permanent address

Each bot gets its own CLI data directory and permanent contact link, so reconnecting users always reach the same bot.

POST /api/admin/bots POST /api/admin/bots/{id}/start|stop|restart GET /api/admin/bots/{id}/qrcode · qr.png
02

No-code rules

Match a keyword, exact phrase or regular expression and reply with a template. Cooldown keeps a chatty user from being spammed.

trigger_type exact · prefix · regex · default cooldown_seconds {sender_name} {time} {bot_name} POST /api/admin/rules/preview
03

Routing and tickets

Forward enquiries into a support group with a #T ticket id; an operator answers with the ticket id and the reply goes back to the customer.

source_type direct · group · any target_type group · contact · broadcast POST /api/admin/routing/preview
