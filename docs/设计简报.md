popopx-bot-studio 定位为 POPOPX 生态的「BotFather + 低代码自动化与插件网关」，与 popopx-service-suite（商业服务号）平行互补，遵循 AGPL-3.0-only 许可且不捆绑底层 CLI 二进制。
以下为你提供完整的 一、系统架构设计与目录蓝图，以及 二、可直接复制发给 qodercli 从零构建并跑通全套自检的完整工程提示词。

二、 可直接发给 qodercli 的完整工程提示词

在你的 Mac 终端克隆 https://github.com/popopx-chat/popopx-bot-studio.git 并进入目录后，把下方完整提示词发送给 qodercli（已内置我们前面踩过的所有 popopx-cli 真实协议细节：/_address_settings JSON 结构、autoAccept: {"acceptIncognito": false}、防 systemd/launchd 剥引号拆词 argv 包装脚本、运行时按需下载 popopx-cli 零二进制分发合规、以及离线全套 --self-test 自检门禁）：
该提示词要求 qodercli 基于 Python 3.11、FastAPI 和 POPOPX/SimpleX 底层协议，从零构建 popopx-bot-studio 平台。核心约束包括：
• AGPL-3.0-only 合规：不捆绑 popopx-cli 二进制，由安装脚本在运行时根据操作系统和架构从 GitHub Releases 动态下载。
• 底层 WebSocket 控制协议：通过回环 WS (ws://127.0.0.1:<port>) 调用 /_address、/_address_settings、/_send 等接口管理 Bot。
• 核心模块：包含多 Bot 生命周期与冷备引擎、零代码规则/路由引擎、开发者 Open API 与 Webhook 网关、可扩展插件系统、赛博风单页 Web 后台、跨平台安装脚本（Ubuntu/macOS）以及 12 组离线 --self-test 自检门禁



提示词概要： 该提示词用于引导 qodercli 在 popopx-bot-studio 仓库中从零构建一套对标 Telegram BotFather 的开源 Bot 平台。内容涵盖 AGPL-3.0-only 协议合规、真实 WebSocket 协议指令、防 argv 剥离的 wrapper 脚本、多 Bot 隔离及冷备导出、零代码规则/路由引擎、4 大内置插件、Open API 以及 Ubuntu/macOS 双平台一键安装脚本与 12 组 --self-test 离线自检门禁。

该工程提示词旨在指导 AI 助手在当前仓库中从零构建 POPOPX Bot Studio 平台，涵盖基于 Python 3.11 与 FastAPI 的异步微服务架构、WebSocket 协议对齐、多 Bot 生命周期管理、零代码规则引擎、跨会话消息路由引擎、可扩展插件体系以及 Ubuntu/macOS 双平台一键安装脚本和离线 --self-test 自检门禁。
